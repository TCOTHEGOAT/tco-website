TCO — THE CHOSEN ONE / WOLF WEBSITE

This is a standalone responsive website.

Preview:
Open index.html in any browser.

Free publishing:
Use GitHub Pages. Create a free public repository, upload:
- index.html
- styles.css
- script.js
- wolf-hero.jpg

Then Repository Settings -> Pages -> deploy from the main branch.

Before going live:
Replace the "#" placeholders in index.html with your real Spotify, Apple Music,
YouTube, Instagram, TikTok, SoundCloud, merch and booking links.

The "Now Playing" control is a visual demo until an actual audio file or music
embed is connected.
